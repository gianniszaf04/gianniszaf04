# Ιωάννης Ζαφείρης

Είμαι φοιτητής στο Τμήμα Ψηφιακών Συστημάτων του Πανεπιστημίου Θεσσαλίας. Τα projects σε αυτό το προφίλ προέρχονται κυρίως από μαθήματα της σχολής, και κάποια τα συνέχισα μόνος μου. Περιλαμβάνουν εφαρμογές web σε PHP και MySQL, ένα μοντέλο σε Python που αναλύει το συναίσθημα σε ελληνικό κείμενο, σχεδίαση ψηφιακών κυκλωμάτων σε SystemVerilog και MATLAB, και μια προσομοίωση σε NetLogo. Αναζητώ θέση πρακτικής άσκησης όπου θα δουλέψω σε πραγματικά projects και θα μάθω δίπλα σε μια έμπειρη ομάδα.
